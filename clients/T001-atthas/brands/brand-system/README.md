# ATTHA’S Brand System

**Version:** 0.1 — Working Brand System  
**Status:** Design direction approved; technical logo masters and font licensing pending  
**Reference:** Client-approved ATTHA’S Burger menu artwork supplied 24 August 2026

This directory translates the existing ATTHA’S identity into an operating system for the master brand, ATTHA’S Restaurant and ATTHA’S Burger. It extends the current identity rather than redesigning it.

## Brand structure

| Level | Role | Core expression |
|---|---|---|
| ATTHA’S | Master brand | Trusted source of generous, flavour-led food |
| ATTHA’S Restaurant | Multi-cuisine dining brand | Warm, authentic, welcoming and considered |
| ATTHA’S Burger | Fast-food brand | Bold, energetic, indulgent and direct |

## Non-negotiables

1. Red is the dominant recognition colour; yellow is an accent, not a competing background.
2. Food must look real, abundant and freshly prepared.
3. Text must remain readable; never place long copy directly over detailed food photography.
4. Burger may be louder than Restaurant, but both must remain recognisably ATTHA’S.
5. Prices, ingredients, availability, halal claims and offers require source verification before publication.
6. Generative imagery is not evidence of the actual product. Label it internally and never represent it as a real menu item without client approval.
