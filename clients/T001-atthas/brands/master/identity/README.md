# Identity — Proposed Rebrand V1

No new identity element in this folder is official until management approval.

## Proposed master palette

| Token | Hex | Role |
|---|---|---|
| Attha's Deep Red | `#8F1D14` | Primary brand anchor |
| Flame Gold | `#F3B61F` | Flavour/energy accent |
| Warm Cream | `#FFF4E3` | Premium warm background |
| Charcoal | `#1D1917` | Type / contrast |
| Herb Green | `#3E6B4F` | Restaurant freshness accent |
| Chilli Red | `#D9412C` | Burger/heat accent |

## Proposed typography

- **Master / premium display:** Fraunces SemiBold
- **Body / UI:** Manrope
- **Burger campaign display:** Barlow Condensed Bold

All are intended as accessible, web-friendly type choices; licensing should be rechecked before final production deployment. The final wordmark should be custom-drawn rather than simply typeset.
