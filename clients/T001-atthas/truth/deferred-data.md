# Deferred ATTHA’S Operational Data

**Decision date:** 2026-08-25

The following data work is intentionally postponed for the current completion sprint:

1. Dine-in + takeaway prices
2. Uber prices / Merchant export freshness
3. PickMe prices / Merchant export
4. Ingredients/descriptions
5. Allergens
6. Offers + validity dates
7. Product availability by branch
8. Real product photographs, SKU/branch mapping and advertising rights

These objects are **not assumed complete or verified**. Existing fact gates, channel scope, freshness rules, conflict handling and visual-truth rules remain mandatory. Any campaign requiring one of these facts must use only a currently admissible verified record or block rather than infer missing truth.

This deferral does not delete previously collected public observations; it only removes these areas from the current sprint's completion criteria.
